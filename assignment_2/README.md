## Model notes

The code uses SKU and category encodings, scaled raw-plus-log numeric features, larger networks, He initialization, ELU, regularization, dropout, learning-rate reduction, and early stopping. Comments connect these methods to `BZAN 554/deep.pdf`. The rate-times-duration model is an additional experiment. Predictions and metrics use the original quantity units.

The split remains 70/15/15; validation is kept separate from training. Scalers and categorical vocabularies are fitted only on training rows. Final model selection requires SKU. Blend weights use validation predictions. Some rows overlap earlier experiments, so this split is a continued benchmark rather than a wholly unseen dataset. Random row splitting can place the same SKU in different sets; it does not measure generalization to entirely new products. Duration must be available at prediction time.

`archive/file_manifest.json` records the original and organized paths. Every moved file was checked byte-for-byte before active code was updated for the new folder layout. Nothing was deleted.
